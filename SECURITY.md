# Security Policy

## Supported Versions

Security updates are supported for the following versions of RescuePulse:

| Version | Supported |
| --- | --- |
| v1.0.x | :white_check_mark: Yes |
| < v1.0 | :x: No |

## Reporting a Vulnerability

We take the security of RescuePulse very seriously. If you identify a security vulnerability, please report it to us responsibly:

1. **Do NOT open a public issue** on GitHub.
2. Email your findings to asifahamed.ece@gmail.com with detaled replication steps.
3. We will acknowledge your report within 48 hours and work with you to analyze and patch the vulnerability.
4. Once resolved, we will publish a security advisory and credit you for the discovery.

Thank you for keeping RescuePulse secure!
